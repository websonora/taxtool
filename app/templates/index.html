Current season workflow

Tax Document Backup Portal

Choose the income tax season, open last year's backup, mark old pages to delete, add current-season documents, and save the final PDF into the selected season folder.

1

Choose income tax season

The season sets both the folder searched for last year's backup and the folder the final PDF is saved into.

2

Select last year's backup PDF

Search the shared folder, or upload a PDF by hand if the share is not reachable.

Shared folder mode

Use this when this Windows app can see T:\INCOME TAX REPORTS. The app normally searches one year before the season, but you can choose a different backup folder.

Upload demo mode

Use this when the server does not have shared-folder access yet.

3

Review last year's pages

Pages are kept by default. Use Marked delete only for pages that should not carry forward.

No document open yet

Open last year's backup in step 2 and its pages appear here as thumbnails.

4

Add current-season documents

New scans are merged after the pages you kept, then saved as one PDF.

Scanned PDFs from ClienteActual

Search T:\INCOME TAX REPORTS\ClienteActual / CienteActual, then choose the new scanned PDFs to merge after the kept old pages.

Manual upload fallback

Use this only if the scanned files are not visible from the scanner folder yet.
